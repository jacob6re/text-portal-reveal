# 文字穿越开场与收拢结尾

输入一段视频和一个字或短词，交付 MP4 与可修改的 HyperFrames 工程。开场先显示文字窗口，再放大展开；结尾先正常播放，再反向缩回文字窗口。

## 输入与默认值

- 必需：本地视频、准确文字。只缺这两项时才追问；没有源视频时不能用教程录屏冒充干净素材。
- 默认：三极泼墨体、纯黑背景、居中文字、文字停留 0.6 秒、转场 1.5 秒、30 fps、保留原声、沿用源视频比例。
- 字体：优先用户指定的 TTF/OTF/TTC；未指定时使用三极泼墨体。首次构建自动从公开来源下载约 20 MB 到输出目录旁的 `.text-portal-fonts/`，校验固定 SHA-256；之后使用缓存。下载失败时保留明确错误，不悄悄换回黑体。字体来源与版权边界见 [references/font-source.md](references/font-source.md)。字体缺字会停止，不以方框代替。
- 初始文字宽度不超过画幅 45%，高度不超过 28%；推荐 1–6 个汉字或一个英文短词。长句优先建议缩短。
- 视频至少比「文字停留＋转场」长 0.2 秒。结尾模式在视频末尾执行转场，随后保持文字窗口；剩余时间正常全屏播放。素材不足时缩短时长或请求更长素材，不擅自循环、定格或变速。
- 工程素材统一为 SDR BT.709 H.264，保留连续时间。HDR 素材需要先生成正确色调映射的 SDR 副本，脚本不会直接丢弃 HDR 信息冒充转换完成。

## 制作

依赖 Python 3.9+、FFmpeg/ffprobe、Node.js 22+ 和 HyperFrames。Python 包见 [scripts/requirements.txt](scripts/requirements.txt)，在任务专用虚拟环境安装，避免修改全局 Python。

运行随 Skill 提供的脚本；把下面路径替换为实际绝对路径。输出目录必须不存在。

```bash
python scripts/build.py --video /path/to/source.mp4 --text '出发' --out /path/to/new-project
```

反向收拢结尾：

```bash
python scripts/build.py --video /path/to/source.mp4 --text 'Jake边做边学' --direction conceal --text-width 0.78 --out /path/to/new-ending
```

`--direction reveal` 为默认开场；`--direction conceal` 为结尾。用户说“反过来／倒放成字”且上下文指转场时，先按反向转场处理并说明；底层视频与音频继续正向播放。只有明确要求素材倒放时才另做时间反转。

常用参数：`--font /path/to/font.ttf`、`--font-index 0`（TTC）、`--hold 0.6`、`--zoom 1.5`、`--start 0`、`--duration 5`、`--fps 60`、`--width 1080 --height 1920`、`--mute`。`hold` 是开场最初／结尾最后的文字停留时长。改变比例会居中裁切填满；先确认关键主体没有被裁掉。`--text-width 0.45` 调整文字窗口宽度比例，较长的品牌短句可用 0.7–0.8 提高可读性。

生成 `index.html`、`hyperframes.json`、`package.json`、`portal.json`、`assets/source.mp4`、`assets/gsap.min.js` 与 `assets/initial-mask.png`。`portal.json` 保存字形、穿入点和时长参数。GSAP 来自 Skill 自带本地文件，字体轮廓转成矢量路径，工程不依赖原字体或远程 CDN。

## 效果不变量

1. 底层只有一段连续播放的视频；放大的是文字遮罩，底层视频不跟随文字缩放、不重新播放。
2. 初始字外严格黑色，字内是原视频。文字间距和字腔保持透明窗口之外的黑色。
3. 自动选择字形实心区域作为穿入／收拢点，以保守内接正方形计算全屏倍率。不能直接围绕两字之间、`O` 或“口”的空洞放大。
4. 开场笔画窗口先覆盖整个画幅，才移除黑色遮挡；结尾从同一个全屏矩阵缩回原字形，末尾保留遮罩。不要用突然切到另一段视频或长溶解掩盖残留黑边。
5. 使用本地 SVG 矢量路径与单条暂停 GSAP 时间线；只由 HyperFrames 控制视频播放，任意拖动时间线应得到同一画面。

## 验证与交付

在生成工程目录运行 `npm run check`，通过后渲染 `npm run render -- --output reveal.mp4`。用户已要求成片或 Skill 行为验证时可直接执行；仅分析或明确暂停时不要渲染。

查看 MP4 的文字停留、转场中段、全屏衔接和最后一帧；用 ffprobe 核对分辨率、fps、时长和原声。重点确认：文字内确实运动、字外纯黑、没有缺字、全屏态没有黑色空洞残留、构图与源时间连续。结尾应从第一帧完整播放，最终文字可读，末尾不能重新展开或跳黑。自动检查通过不能替代实际帧检查。

明确交付本地 MP4、工程和 Skill 路径；如只通过结构检查，直说尚未验证成片。制作、安装与发布是不同动作；不因制作请求而上传视频或创建远端仓库。

仅支持按字形逐字排版的中文、拉丁文与数字等文字。复杂连写、双向排版与组合字符需要额外排版实现，脚本会拒绝，不能声称已支持。
